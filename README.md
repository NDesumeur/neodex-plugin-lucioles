# Lucioles

Un pré la nuit : toucher une luciole l'allume ou l'éteint, elle et ses quatre voisines. Allume-les toutes.

Chaque pré commence avec des lucioles éteintes. Toucher une luciole l'inverse, avec ses quatre voisines. Le but : toutes allumées. Chaque pré est toujours faisable ; les suivants demandent plus de coups.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Lucioles → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
